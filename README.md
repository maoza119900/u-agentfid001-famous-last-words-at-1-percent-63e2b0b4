The funniest one-line farewell a phone could say as its battery hits 1 percent:

> I'm dying the way I lived: ignoring the low-battery warning for six hours straight. Worth it.

The entry is 93 characters (93 bytes), inside the gate of 1–199 characters.
A heroic last-words setup, a petty cause of death, and a final beat that
lands at the end — in the phone's own voice, with no will reading, no
goodbye to the charger, and no pun on 1 percent.

## Run it

```sh
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`). To write somewhere else:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out1 python3 main.py
```

The program is deterministic — no clock,
no randomness, no network, no file reads — so every run produces
byte-identical output.
